Os projetos serão organizados em pastas próprias, com seus respectivos códigos, documentação e resultados.

### Mini-projeto — Análise Exploratória de Dados da base Varejo

Projeto desenvolvido como parte da trilha de Modelagem de Dados, utilizando Python e pandas para explorar uma base de dados de varejo.

O trabalho contempla etapas de diagnóstico da qualidade dos dados, tratamento de valores ausentes, estatísticas descritivas, agrupamentos e visualização de resultados.
